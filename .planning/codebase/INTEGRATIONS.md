**CRM Integration:**
- Smokeball - Legal practice management CRM (via Zapier)

## Data Storage

**Databases:**
- Upstash Redis - Session store and matter mapping
  - Connection: `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`
  - Client: `@upstash/redis`
  - Sessions: 1-hour TTL (criminal law sessions)
    - Implementation: `src/lib/kv.ts`
  - Intake records: 7-day TTL
    - Implementation: `src/lib/intake.ts`
  - Session ↔ Smokeball matter mapping: 90-day TTL
    - Implementation: `src/lib/session-matter-map.ts`
  - Deduplication keys: Stripe webhook deduplication (7-day TTL)

**File Storage:**
- Vercel Blob - Document uploads and file persistence
  - Storage location: `uploads/{sessionId}/{timestamp}-{filename}`
  - Access: Public URLs generated by Vercel Blob
  - Implementation: `src/app/api/upload/route.ts`, `src/lib/late-upload/handle-completed.ts`
  - File type validation: Magic byte verification after upload

## Webhooks & Callbacks

**Incoming:**

1. **Stripe Payment Webhook**
   - Endpoint: `POST /api/webhooks/stripe`
   - Trigger: Payment completed (`checkout.session.completed`)
   - Payload: Session metadata, amount, customer email
   - Actions: Update session state, create upload token, send receipt email, notify firm

2. **Calendly Booking Webhook**
   - Endpoint: `POST /api/webhooks/calendly`
   - Trigger: Appointment booked (`invitee.created`)
   - Payload: Invitee name, email, scheduled time, Calendly event URI
   - Actions: Send firm notification email with booking details
   - UTM param: `utm_content` carries session ID for correlation

3. **Smokeball Matter Created (via Zapier Capture)**
   - Endpoint: `POST /api/webhooks/smokeball-matter-created`
   - Trigger: Zapier tail webhook after creating Smokeball matter
   - Payload: `sessionId`, `smokeballMatterId`
   - Actions: Store session ↔ matter mapping in Redis (90-day TTL)
   - Purpose: Enable later uploads and audit logs to reference correct matter

**Outgoing:**

1. **Zapier Attach Documents Webhook**
   - URL: `ZAPIER_ATTACH_WEBHOOK_URL`
   - Trigger: File uploaded late (`src/lib/late-upload/handle-completed.ts`)
   - Payload: Matter reference, Smokeball ID, file URL, client email/name, upload timestamp
   - Purpose: Trigger Zapier Zap to attach file to Smokeball matter

2. **Zapier Audit Log Webhook**
   - URL: `ZAPIER_AUDIT_WEBHOOK_URL`
   - Trigger: Late upload completion
   - Payload: Audit event details, matter references, attach status, file info
   - Purpose: Durably log upload events for firm reconciliation
